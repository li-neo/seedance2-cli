# 模式映射与自动识别 (`mode-mapping.md`)

本文档详细说明 `seedance2-cli` Skill 内部如何根据用户输入自动识别视频生成模式，并概述了其优先级、置信度评估及回退策略。

---

## 1. 核心设计理念

新的模式识别逻辑由 `scripts/select_mode.py` 脚本实现，其核心目标是：

- **解耦与可测试**：将模式判断逻辑从主流程 `pipeline.py` 中剥离，使其成为一个独立的、可进行单元测试的纯函数模块。
- **规则显式化**：通过清晰的优先级规则，处理复杂的素材组合，避免隐晦的 `if/else` 嵌套。
- **置信度评估**：为每种决策提供一个置信度分数和文本理由，便于调试和日志追溯。
- **智能回退**：在遇到模糊或不完整的输入时，能够优雅地降级到最稳定或最可能的模式，并向用户提供告警信息。

---

## 2. 素材类型解析

在进行模式判断前，脚本首先会解析所有传入的媒体文件，并将其归类为以下几种 `kind`:

| 类型 (`kind`) | 识别依据 (文件扩展名) | 备注 |
| :--- | :--- | :--- |
| `image` | `.png`, `.jpg`, `.jpeg`, `.webp`, `.bmp`, `.gif` | 通用图片类型。 |
| `pose` | 图片类型 + 文件名包含 `_pose`, `pose_`, `_skeleton`, `skeleton_` | 姿态图，作为图片的子类处理。 |
| `segmentation`| 图片类型 + 文件名包含 `_seg`, `seg_`, `_mask`, `mask_` | 分割图或蒙版，作为图片的子类处理。 |
| `video` | `.mp4`, `.mov`, `.mkv`, `.webm`, `.avi` | 视频文件。 |
| `audio` | `.mp3`, `.wav`, `.aac`, `.m4a`, `.ogg`, `.opus`, `.flac` | 音频文件。 |
| `other` | 无法识别的扩展名 | 归为此类，通常在模式判断中被忽略。 |

---

## 3. 模式识别规则与优先级

`select_mode_from_materials` 函数遵循以下**从高到低的优先级**来决策生成模式 (`ModeDecision.mode`)：

| 优先级 | 条件 (素材组合) | 判定模式 | 置信度 | 备注 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | **无任何**图片/视频/音频素材 | `t2v` | 0.95 (有文本) / 0.6 (无文本) | 最基础的文生视频模式。若连文本都缺失，会给出告警。 |
| 2 | **仅有 1 个视频**，无其他素材 | `multimodal_ref2v` | 0.95 | 视频续写/编辑场景，通过 `multimodal_ref2v` 实现。 |
| 3 | **仅有图片** (无视频/音频) | | | 根据图片数量细分： |
| | - 只有 1 张图片 | `i2v` | 0.95 | 标准的图生视频（首帧驱动）。 |
| | - 只有 2 张图片 | `fl2v` | 0.95 | 标准的首尾帧生成视频。 |
| | - 有 3 张或更多图片 | `multi_i2v` | 0.90 | 多图参考生成，如故事板、多视角角色。 |
| 4 | **仅有音频** (无图片/视频) | `multimodal_ref2v` | 0.60 | 纯音频驱动能力有限，会给出告警，建议补充视觉参考。 |
| 5 | **任意其他混合** | `multimodal_ref2v` | 0.90 | 覆盖所有其他组合，如“视频+图片”、“图片+音频”、“多视频”等。 |

---

## 4. 模式到 Seedance API 的映射

判断出的细分模式 (`ModeDecision.mode`) 在最终调用 `seedance_cli.py` 时，会通过 `ModeDecision.seedance_mode` 属性映射为 Seedance API 支持的核心模式：

| 细分模式 (本地) | 映射到 Seedance API 模式 | 理由 |
| :--- | :--- | :--- |
| `t2v` | `t2v` | 直接透传。 |
| `i2v` | `i2v` | 直接透传。 |
| `fl2v` | `fl2v` | 直接透传。 |
| `multi_i2v` | `multimodal_ref2v` | 多图输入属于多模态参考范畴，通过多图参考进行视频生成。 |
| `multimodal_ref2v` | `multimodal_ref2v` | 直接透传。但有一个特殊回退： |
| | *(仅音频)* `multimodal_ref2v` | `t2v` | **核心降级策略**：为避免 `seedance_cli.py` 对纯音频 `multimodal_ref2v` 的限制导致执行失败，当检测到**仅有音频输入**时，模式会**降级为 `t2v`**。此时，音频素材的信息需要通过文本提示词（Prompt）来辅助表达。 |

通过这层映射，Skill 内部可以拥有更丰富的模式语义来指导逻辑，同时保证了对外部服务接口调用的兼容性和稳定性。
